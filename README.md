# SigmaOS-installer

Installer component for SigmaOS — installation state machine for the partition/copy/bootloader flow. Disk operations are future work.

- **Category:** Utilities
- **Engine:** installer
- **Language:** Rust

## Build & Test

```sh
cargo build
cargo test
```

Part of the SigmaOS multi-repository component ecosystem.
